# Fake News Detection Using NLP and Machine Learning

## Project Overview
This project predicts whether a news article may be fake or real
using Natural Language Processing (NLP) and Machine Learning.

## Technologies Used
- Python
- Scikit-learn
- TF-IDF Vectorization
- Linear Support Vector Classifier (LinearSVC)
- Streamlit

## How to Run
1. Install the required packages:
   pip install -r requirements.txt

2. Start the application:
   streamlit run app.py

## Project Files
- app.py: Web application
- best_model_week3.pkl: Trained machine-learning model
- tfidf_week3.pkl: Trained TF-IDF vectorizer
- requirements.txt: Required Python packages

## Disclaimer
Predictions are machine-learning estimates and do not establish
whether a news article is factually true or false.
